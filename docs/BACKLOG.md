# Бэклог

Что дальше после релиза 26103108 (Ф0..Ф4 и из Ф5 маппер, OPLL, меню-дерево, Nextor сделаны, см. `PLAN.md`). Следующий пункт — физический дисковод Go. Порядок Ф5 (пользователь,
2026-10-31): memory mapper → OPLL (и SCC MegaRAM, если влезет) → Nextor на образе HDD → физический
дисковод Go; остальное потом. Одна ветка и один PR на пункт.

## Ф5. Расширения

- ~~**Memory mapper**~~: сделан (512 КБ в SRAM с 080000, PR #7, сборка 26103104 Mini G проверена на железе).
- ~~**OPLL**~~: сделан (MSX-MUSIC на `jt2413`, PR #8, сборка 26103105 Mini G проверена на железе).
- **Меню-дерево OSD**: сделано (PR #9, 26103106 Mini G проверена на железе).
- **ESE-SCC MegaRAM** (SCC-картридж с RAM, загрузка образов игр Konami) и **FM-PAC** (маппер
  7FF4–7FF6, SRAM 8 КБ) — опциями OSD, если останется место (Mini G уже 88 % slices: скорее всего что-то одно).
- ~~**Nextor на образе HDD**~~: сделан (`nextor_sd.v`, PR #10); эмулятор SD-карты проверен на
  железе `sdtest.rom`, сам Nextor — нет (нужен BIOS, см. ниже).
- **Сохранения картриджей с батарейкой** (Game Master 2, ASCII 8 / 16 с SRAM): `.sav` через
  `kg_bk_ram` (caps bit 3, как у NES).
- **Физический дисковод** Karabas Go (`F` с флагом `physical`, как у NanoMig).
- **Turbo** и **576p50** для PAL (настоящие 50 Гц на выходе вместо 60).

## Открытые вопросы и непроверенное

- **С настоящим BIOS MSX1** (пользователь его достанет; на SD-карте Mini G уже есть `/msx/NEXTOR.ROM`
  и `/msx/nextor.img` — 32 МБ, MBR + FAT16 с `NEXTOR.SYS`, `COMMAND2.COM`, `DOS/`, `HELP/`):
  1. Nextor: Machine > BIOS = дамп, Slot 1 = Nextor, Slot 1 ROM = On, HDD = `nextor.img` — заставка
     Nextor, `A>`, `DIR`, `DIR DOS`, запись файла (`COPY CON`), перезапуск и файл на месте; смена
     образа HDD во время работы (флаг смены диска); `CALL SYSTEM` / `BASIC` туда и обратно.
  2. Memory mapper под Nextor: свободная память в `A>` (`DRVINFO`, `MAPDRV`), 512K / 64K.
  3. Дисковод с Disk ROM: Slot 1 = Disk drive, Slot 1 ROM = On — Disk BASIC (`FILES`, `SAVE` /
     `LOAD`), DSK-игры.
  4. Кассета: CAS-игры (`RUN"CAS:"`, `BLOAD"CAS:",R`), `CLOAD` / `CSAVE` через TAPE_IN / TAPE_OUT.
  5. MSX-MUSIC с BIOS: игры, которые ищут `APRLOPLL`.

- Go и Mini (26103108) на железе не проверены.
- `TAPE_IN` / `TAPE_OUT` не проверены (нет магнитофона).
- DSK-игры, Disk BASIC и CAS-игры с настоящим BIOS MSX не проверены (у пользователя нет BIOS);
  с C-BIOS проверены только тестовые картриджи `fdctest` / `tapetest`.
- Джойстики на железе не проверены, загрузка BIOS из файла — тоже.
- Симуляция: клавиатура не доходит до программы (BIOS не меняет строку матрицы, на железе работает) —
  разобраться в стенде (`keys.rom`, `SIM_KBDBG`, `SIM_ISR`).
- Защита от записи образа диска (прошивка не передаёт read-only) и смена диска во время работы
  программы — отдельно не тестировались.
- Запас по таймингу: худший путь внутри T80 (0,5–2,8 нс в зависимости от размещения); при росте ядра
  (Ф5) может понадобиться конвейеризация или `-t` другой. В 26103108: Mini 0,46 нс, Mini G 0,37 нс (путь T80 IR → регистр `konami_scc`), Go 3,93 нс.
- Прошивка: `core_ioctl_send` шлёт `IOCTL_STATE` 1 раньше `IOCTL_SLOT` — ядро это обходит
  (`file_reset`), но порядок можно поправить в прошивке для всех ядер.
